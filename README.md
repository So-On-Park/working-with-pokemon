## ✨ 함께 할 수 있는 것

|  |  |
|---|---|
| 🕹️ **추억의 그 포켓몬** | 어릴 적 함께하던 그 포켓몬을, 이제 모니터 펫으로 다시 키워요 |
| 🏡 **함께 사는 파티** | 최대 세 마리를 데스크탑에 꺼내두고 같이 지내요 |
| 💛 **키우는 재미** | 쓰다듬고 · 먹이 주고 · 놀아주며 친밀도와 레벨업, 그리고 진화까지 |
| 🌿 **야생 포켓몬** | 화면에 깜짝 등장하는 야생을 잡아 도감을 채워요 |
| 🎨 **나만의 포켓몬** | 직접 만든 GIF를 새 포켓몬으로 등록할 수 있어요 |
| 🔔 **리마인더** | 물 마시기·스트레칭처럼 놓치기 쉬운 루틴을 버디가 챙겨줘요 |

## 🚀 시작하기

1. **[최신 버전 다운로드](https://github.com/So-On-Park/working-with-pokemon/releases/latest)** → 설치 파일 실행
2. 모험자 이름을 정하고, 포켓볼 하나를 골라요
3. 실루엣 속 첫 친구를 만나면 — 모험 시작! 🎉

<sub>설치·업데이트·데이터 이전은 **[UPDATING.md](UPDATING.md)** 를 참고하세요.</sub>
